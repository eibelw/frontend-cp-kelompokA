# Frontend Capstone Project Kelompok A

## Struktur Proyek

```
frontend/
├── index.html              ← Dasar HTML
├── tailwind.config.ts      ← Konfigurasi styling tailwind
├── tsconfig.json           ← Konfigurasi styling tailwind
├── tsconfig.node.json      ← Konfigurasi styling tailwind
├── vite.config.json        ← Konfigurasi dasar react JS
├── package-lock.json       ← Konfigurasi struktur FE
├── package.json            ← Konfigurasi struktur FE
└── src/
    ├── api/
    ├── aset/
    ├── fitur/
    ├── halaman/
    ├── hooks/
    ├── komponen/
    ├── konteks/
    ├── tipe/
    ├── utils/
    └── main.tsx
```

## Installation

Menggunakan node js sebagai paket manajer. Jika sudah terinstall jalankan:

```bash
npm install
```

## Usage

```python
npm run dev
```

### Notes

- Pastikan backendnya sudah jalan terlebih dahulu
